# Logo — assets oficiais

logo-full.svg e logo-mark.svg são os vetores oficiais fornecidos para a
marca EMR Despachantes. O componente Logo renderiza estes arquivos sem
alterar seus paths, proporções ou cores.

Ao atualizar a identidade visual, substitua os dois arquivos pelas novas
fontes oficiais e atualize também apps/web/src/app/icon.svg com o conteúdo
de logo-mark.svg.
